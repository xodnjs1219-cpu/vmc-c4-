# 제품 요구사항 명세서(PRD): 실시간 채팅 서비스

**문서 버전:** 1.1
**작성일:** 2025-10-17

-----

## 1. 제품 개요 (Product Overview)

사용자가 온라인에서 실시간으로 채팅방을 개설하고 참여하여 자유롭게 소통할 수 있는 웹 기반 커뮤니케이션 플랫폼.

핵심 목표는 다음과 같다.

1.  간편한 인증 절차를 통해 서비스 접근 장벽을 낮춘다.
2.  누구나 직관적으로 채팅방을 만들고 참여할 수 있는 사용자 경험을 제공한다.
3.  이모티콘, 답장, 좋아요 등 풍부한 인터랙션 기능을 통해 실시간 소통의 재미와 깊이를 더한다.

## 2. Stakeholders

  * **User (사용자):** 회원가입 및 로그인 / 채팅방 목록 탐색 / 채팅방 생성 및 참여 / 실시간 메시지 전송 및 상호작용 / 내 정보 관리

## 3. 포함 페이지 (Included Pages)

### 로그인

  - 이메일, 비밀번호 입력 폼
  - 회원가입, 비밀번호 찾기 페이지로 연결

### 회원가입

  - 닉네임, 이메일, 비밀번호, 비밀번호 확인 입력 폼
  - 비밀번호 정책(8자 이상) 안내

### 홈 (채팅방 목록)

  - 전체 채팅방 목록 표시 (채팅방 이름, 개설자 닉네임)
  - 새 채팅방 만들기, 마이페이지, 로그아웃 기능

### 새 채팅방 만들기

  - 채팅방 이름 입력 폼 (최대 100자)

### 채팅방

  - 실시간 메시지 타임라인
  - 메시지 입력창 (텍스트, 이모티콘)
  - 메시지 상호작용 기능 (좋아요, 답장, 내 메시지 삭제)

### 마이페이지

  - 가입 정보(이메일, 닉네임, 가입일) 표시
  - 닉네임 수정 기능

## 4. 사용자 여정 (User Journey)

### 4.1 신규 사용자의 채팅방 생성 및 참여 여정

1.  웹사이트에 접속하여 로그인 페이지의 '회원가입'을 통해 가입을 진행한다.
2.  가입 완료 후 로그인하면 채팅방 목록이 있는 홈 화면으로 이동한다.
3.  '새 채팅방 만들기' 버튼을 눌러 원하는 이름의 채팅방을 생성한다.
4.  홈 목록에 생성된 자신의 채팅방을 클릭하여 입장한다.
5.  메시지 입력창을 통해 다른 사용자들과 실시간 대화를 시작한다.
6.  다른 사람의 메시지에 '좋아요'를 누르거나 '답장' 기능을 사용해 소통한다.

### 4.2 기존 사용자의 정보 수정 여정

1.  로그인 후 홈 화면의 '마이페이지'로 이동한다.
2.  현재 설정된 자신의 닉네임, 이메일 등 정보를 확인한다.
3.  닉네임 옆의 '수정' 버튼을 눌러 새로운 닉네임으로 변경 후 저장한다.

## 5. IA (Information Architecture)

```
/ (로그인 페이지로 리디렉션)
│
├─ /auth
│  ├─ /login (로그인)
│  ├─ /signup (회원가입)
│  └─ /forgot-password (비밀번호 찾기)
│
└─ /app (인증 후 접근)
   ├─ / (홈, 채팅방 목록)
   ├─ /create-room (채팅방 생성)
   ├─ /room/[roomId] (채팅방)
   └─ /my-page (마이페이지)
```
